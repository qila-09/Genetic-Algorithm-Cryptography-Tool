# Genetic Algorithm Substitution Cipher Solver

A C++ program that breaks monoalphabetic substitution ciphers using a genetic
algorithm, scoring candidate keys against English n-gram statistics.

## Summary
- **Language:** C++17 (no external libraries)
- **Purpose:** Encrypt text with a random substitution key, or recover the
  plaintext from ciphertext with no key, by evolving candidate keys.
- **Scale:** 6 source files, 4 classes, 386 lines of code
  (plus a separate n-gram frequency counter, 184 lines)

## How it works
1. **Key representation:** each candidate key is a permutation of the alphabet
   (a `Gene`).
2. **Fitness:** decrypt the ciphertext with the candidate key, then sum the
   log-probabilities of every n-gram (default n = 4) from a frequency table.
   Unseen n-grams get a small floor score. Log-probabilities avoid underflow
   and turn products into sums.
3. **Selection:** the top 5% of each generation become elites and are carried
   over unchanged, so the best score never decreases.
4. **Crossover:** a random segment is copied from one parent, then the
   remaining letters are filled in from the other parent in order,
   keeping the key a valid permutation with no duplicates.
5. **Mutation:** random swaps of two letters in the key.
6. **Termination:** program ends after a fixed number of generations (default 750)
   or when there is no increase in accuracy for 75 generations.

## Object-oriented design
| Class | Responsibility |
|---|---|
| `Substitution` | Generates a random key; encrypts and decrypts text |
| `NgramTable` | Loads n-gram counts from file and stores log-probabilities |
| `Gene` | One candidate key; applies, mutates and crosses over keys |
| `GA` | Population, scoring, selection and generation loop |

## Data structures
- `std::unordered_map<std::string, double>`: n-gram -> log-probability,
  O(1) average lookup
- `std::vector<Gene>` / `std::vector<double>`: population and scores
- Fixed-size `bool used[26]` array in crossover for O(1) duplicate checks

## Interesting implementation details
- User has the choice to run on preset configuration or to set their own values
  for the algorithm to use. They can change population size, mutation rate,
  n-gram size, and maximum number of generations.
- Crossover is a variation on order crossover (OX): a random segment is copied
  from one parent, then each remaining letter keeps its position from the other
  parent where that slot is free, and the rest fill the gaps in order.
- Elitism means that accuracy increases at a much faster rate while it is
  also never lost even with mutations and crossovers loosing accuracy.
- After 75 of generations with no improvement the algorithm stops to
  prevent unnecessary waiting

## Results
On ciphertext of around 1000 character, the algorithm finds the correct
key in more than 90% of runs, typically within 150 generations and the
success rate increases to 100% when the convergence detection is removed.
Short ciphertexts are harder because there is less statistical signal.

## Build and run
    g++ -std=c++17 -O2 main.cpp ga.cpp Gene.cpp Ngrams.cpp Substitution.cpp -o cipher
    ./cipher

The program needs a file named `4gram.txt` in the working directory. This
can be generated by running the n-gram counter on a text corpus saved in
the same working directory and stored as a .txt file. The corpus and
generated files are not included, as requested.
